# هاشم SMS

تطبيق أندرويد عربي لإدارة رسائل SMS والمحادثات، مع واجهة RTL ودعم المظهرين الفاتح والداكن.

## الواجهة الرئيسية

- التبويبات الرئيسية، بالترتيب: الكل، غير مقروءة، لم يتم الإرسال، جماعية، غير معروف، مجدولة.
- شريط التبويبات قابل للتمرير أفقيًا.
- عنوان «هاشم SMS» مضبوط على 28sp.
- المحادثات المؤرشفة والمهملات والرسائل غير المرغوب فيها والأرقام المحظورة متاحة من القائمة الجانبية.
- إعدادات الرسائل، والنسخ الاحتياطي والاستعادة، والمساعدة والملاحظات ضمن القائمة الجانبية.
- إدارة مجموعات المستلمين جزء من قسم الرسائل الجماعية، وليست تبويبًا رئيسيًا.

## الوظائف الموجودة في المشروع

- عرض المحادثات والبحث فيها وربط الأرقام بأسماء جهات الاتصال عند توفر الإذن.
- إرسال SMS وإعادة إرسال الرسائل الفاشلة، مع إظهار خيار التوجيه فقط عند وجود قواعد توجيه محفوظة.
- جدولة الرسائل ومحاولة استعادة المواعيد بعد إعادة تشغيل الجهاز.
- أرشفة المحادثات، ونقل الرسائل إلى المهملات واستعادتها، وحظر الأرقام.
- رسائل جماعية، واستيراد قائمة مستلمين، وتخصيص نص الرسالة باستخدام `{name}`.
- إنشاء مجموعات المستلمين وإضافة الأعضاء وإعادة استخدام المجموعة في الرسائل الجماعية.
- وضع نجمة للرسالة من قائمة المزيد داخل المحادثة؛ لا توجد شاشة مستقلة لقائمة الرسائل المميزة.
- قواعد التوجيه المحفوظة تظل بيانات تشغيلية؛ لا تُعرض واجهة مستقلة لإدارتها في التصميم المعتمد.

## خطة التطوير والتسليم

التطوير الجاري على الفرع الخاص `phase1-ui` في مستودع Private. العمل مقسم إلى أربع دفعات A وB وC وD، ولكل دفعة Commit مستقل وفحوص GitHub Actions.

- لا يُعد نجاح البناء وحده اعتمادًا للدفعة؛ يجب نجاح البناء واختبارات الوحدة وAndroid Lint، مع عدم تجاوز 14 تحذيرًا.
- لقطات الشاشة تُنتج كـArtifact صور للوضعين الفاتح والداكن، ولا تُعد إصدارًا أو APK للتثبيت.
- لا يصدر APK نهائي ولا Release ولا يُطلب التثبيت قبل اعتماد الدفعات الأربع.
- اختبار الهاتف الحقيقي مؤجل إلى قائمة تحقق التسليم النهائي. نجاح CI لا يعني أن التطبيق اختُبر على هاتف فعلي.
- لا يتم دمج طلب السحب في `main` دون موافقة صريحة.

## البناء للمطورين

يمكن بناء نسخة تطوير محلية باستخدام Gradle أو سكربت Termux المرفق. ملفات APK الناتجة عن البناء المحلي أو CI ليست إصدارًا نهائيًا ولا يُطلب تثبيتها أثناء تنفيذ الدفعات.

## ملاحظات التوافق

يتطلب تكامل SMS الكامل منح أذونات أندرويد اللازمة وتعيين هاشم SMS كتطبيق الرسائل الافتراضي. دعم MMS وRCS ليس جزءًا من تأكيدات هذا المستند؛ يجب التحقق من كل وظيفة على حدة قبل إعلان دعمها.
