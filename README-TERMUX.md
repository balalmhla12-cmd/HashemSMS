# هاشم SMS — إصدار 1.2

## المزايا المضافة
- واجهة رسائل عربية مستوحاة من Google Messages بدون نسخ أصول Google.
- الضغط المطول على الرسالة يفتح وضع التحديد المتعدد.
- تحديد أكثر من رسالة.
- تحديد الكل.
- نسخ الرسائل المحددة.
- حذف الرسائل (نقلها إلى المهملات).
- تمييز/إلغاء النجمة ★.
- إعادة توجيه الرسائل المحددة إلى رقم آخر.
- بحث داخل المحادثة مع تصفية فورية للنتائج.
- قواعد توجيه مسماة للرسائل الفاشلة: حفظ اسم القاعدة ورقم بديل، ثم اختيار القاعدة يدويًا لتوجيه نسخة من الرسالة.
- توجيه يدوي واضح مع تأكيد قبل إرسال محتوى الرسالة إلى الرقم البديل؛ لا يوجد توجيه تلقائي خفي.
- بحث عام في قائمة المحادثات يعمل مع التبويبات.
- زر بحث مستقل داخل المحادثة.

## البناء في Termux
```bash
chmod +x build-termux.sh
./build-termux.sh
```
الناتج: `dist/HashemSMS-debug.apk`

ملاحظة: يجب أن يكون التطبيق هو تطبيق SMS الافتراضي للحصول على تكامل SMS الكامل على إصدارات Android الحديثة.
