# هاشم SMS

تطبيق أندرويد عربي للرسائل النصية القصيرة (SMS)، بواجهة بسيطة لإدارة المحادثات وإرسال الرسائل.

## الوظائف الموجودة في المشروع

- عرض المحادثات والبحث فيها ومحاولة إظهار أسماء جهات الاتصال.
- شاشة محادثة تدعم إرسال SMS، ونسخ الرسائل وإعادة توجيهها ووضع نجمة عليها.
- قسم للرسائل التي تعذّر إرسالها، مع محاولة إعادة الإرسال أو إرسال نسخة عبر قاعدة توجيه يختارها المستخدم.
- قواعد توجيه مسماة، تتضمن رقمًا بديلًا، مع تأكيد قبل إرسال محتوى الرسالة إلى الوجهة البديلة.
- جدولة الرسائل بتاريخ ووقت يحددهما المستخدم، وإلغاء الجدولة قبل الإرسال، ومحاولة استعادة المواعيد بعد إعادة تشغيل الجهاز.
- أرشفة المحادثات وحظر الأرقام وإخفاء إشعارات الرسائل الواردة من الأرقام المحظورة.
- المهملات مع استعادة الرسائل أو حذفها نهائيًا.
- رسائل جماعية، واستيراد قائمة مستلمين من ملف نصي أو CSV، وتخصيص نص الرسالة باستخدام `{name}`.
- إدارة مجموعات المستلمين: إنشاء مجموعات، إضافة أعضاء أو حذف المجموعة، وإعادة استخدام المستلمين في الرسائل الجماعية.
- فحص Android Lint وبناء APK تجريبي تلقائيًا عبر GitHub Actions عند تحديث الفرع `main`.

## تنزيل نسخة تجريبية

1. افتح [عمليات البناء](https://github.com/balalmhla12-cmd/HashemSMS/actions).
2. افتح أحدث عملية باسم **Build HashemSMS APK** وانتظر حتى تنتهي بنجاح.
3. نزّل الملف **HashemSMS-debug-apk** من قسم **Artifacts**.

> تنبيه: نجاح البناء يؤكد أن المشروع اجتاز الفحوص المحددة وأن APK قد أُنشئ، لكنه لا يثبت أن كل الوظائف اختُبرت على هاتف فعلي. استقبال الرسائل وإرسالها يعتمدان على منح الصلاحيات وتعيين هاشم SMS كتطبيق الرسائل الافتراضي في أندرويد. دعم MMS وRCS غير مكتمل في هذه النسخة.

يوجد سكربت باسم `build-termux.sh` لمحاولة إعداد أدوات البناء وتجميع APK تجريبي محليًا.
