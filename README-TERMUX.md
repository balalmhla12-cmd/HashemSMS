# هاشم SMS — دليل البناء المحلي عبر Termux

هذا الدليل مخصص للمطور الذي يريد اختبار عملية البناء محليًا على أندرويد. ملف APK الناتج هنا نسخة تطوير، وليس إصدار التسليم النهائي.

## البناء

```bash
chmod +x build-termux.sh
./build-termux.sh
```

قد ينتج السكربت ملفًا في `dist/HashemSMS-debug.apk` بحسب بيئة Termux وإعداداتها.

## الوظائف المعروفة في المشروع

- واجهة عربية RTL للمحادثات والبحث.
- إرسال SMS وإعادة محاولة الرسائل الفاشلة.
- خيار توجيه يدوي للرسائل الفاشلة عند وجود قواعد محفوظة، مع تأكيد قبل الإرسال.
- وضع نجمة للرسائل من قائمة المزيد داخل المحادثة.
- جدولة الرسائل.
- الأرشفة والمهملات والحظر.
- الرسائل الجماعية وإدارة مجموعات المستلمين.
- التبويبات الرئيسية: الكل، غير مقروءة، لم يتم الإرسال، جماعية، غير معروف، مجدولة.

## تنبيهات

- لا تثبّت أي APK تجريبي أثناء تنفيذ الدفعات A وB وC وD؛ التسليم النهائي سيكون بعد اعتماد الدفعات الأربع فقط.
- نجاح البناء لا يثبت عمل الإرسال والاستقبال على هاتف فعلي.
- يتطلب تكامل SMS الكامل منح أذونات أندرويد اللازمة وتعيين هاشم SMS كتطبيق الرسائل الافتراضي.
- اختبارات الهاتف الحقيقي ستُسلّم في قائمة تحقق مع النسخة النهائية.
