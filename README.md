# هاشم SMS

تطبيق أندرويد للرسائل النصية القصيرة (SMS)، بواجهة عربية.

## ما هو موجود حاليًا

- قائمة المحادثات والبحث فيها، مع محاولة عرض اسم جهة الاتصال عند توفره.
- شاشة محادثة بفقاعات رسائل، مع نسخ الرسائل وإعادة توجيهها وحذفها ووضع نجمة عليها.
- قسم لمراجعة الرسائل التي تعذّر إرسالها ومحاولة إعادة إرسالها.
- رسائل جماعية مع مراجعة المستلمين قبل الإرسال، ودعم `{name}` لتخصيص النص بالاسم.
- حفظ مجموعات مستلمين وإعادة استخدامها في الرسائل الجماعية.
- جدولة رسالة نصية لإرسالها بعد دقيقة، مع متابعة نتيجة الإرسال.
- سير عمل GitHub Actions لبناء نسخة APK تجريبية عند تحديث الفرع `main`.

## تنزيل نسخة تجريبية

1. افتح [عمليات البناء](https://github.com/balalmhla12-cmd/HashemSMS/actions).
2. افتح أحدث عملية باسم **Build HashemSMS APK**.
3. إذا انتهت بنجاح، نزّل الملف **HashemSMS-debug-apk** من قسم **Artifacts**.
4. إذا فشل البناء، افتح سجل العملية لمعرفة سبب الفشل.

> تنبيه: لا تعتبر النسخة جاهزة للاستخدام قبل نجاح البناء وتجربتها على جهاز فعلي. استقبال الرسائل وإرسالها يعتمدان على منح التطبيق الصلاحيات وتعيينه تطبيق الرسائل الافتراضي في أندرويد. دعم MMS وRCS غير مكتمل في هذه النسخة.

## البناء من Termux

شغّل السكربت الموجود باسم `build-termux.sh` من مجلد المشروع. سيحاول تثبيت أدوات البناء وتجميع APK تجريبي، ثم وضعه داخل `dist/HashemSMS-debug.apk`.
