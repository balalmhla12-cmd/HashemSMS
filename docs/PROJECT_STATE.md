# HashemSMS — حالة المشروع

آخر تحديث: 2026-10-18

## الهدف
تطبيق SMS أندرويد حقيقي باللغة العربية باسم «هاشم SMS»، بالحزمة الثابتة `com.hashem.sms`، مع تصميم Material 3 يدعم RTL والوضعين الفاتح والداكن، دون تغيير سلوك الرسائل المحمي.

## القيود الثابتة
- لا تغيير للحزمة `com.hashem.sms` أو خصوصية المستودع.
- لا حذف أو تغيير منطق: الاستقبال والإرسال، شريحتان، الجدولة، الرسائل الجماعية والمجموعات، المهملات، الفاشلة، قواعد التوجيه، الأرشيف، الحظر، المميزة، البحث، التحديد المتعدد، وتحسينات الأداء.
- ممنوع الألوان الصريحة في Java؛ الألوان من موارد Android.
- تباين النص المستهدف لا يقل عن 4.5:1.
- تحذيرات Android Lint لا تزيد عن 15.
- لا شعار Google ولا أيقونات Google؛ الأيقونات من Material Symbols/VectorDrawable حسب المواصفات.
- لا تثبيت APK بعد كل مرحلة؛ التثبيت والاختبار على هاتف حقيقي ضمن خارطة الطريق.
